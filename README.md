# 💣 SPIKE PROTOCOL — 발로란트식 3D 멀티 FPS

친구랑 같이 하는 5v5 택티컬 FPS. 공격팀은 스파이크 설치, 수비팀은 저지/해체.
7점 선취 승리, 6라운드 후 공수교대 (발로란트 하프타임 오마주).

## 실행법

```bash
cd valorant-like-fps
npm install
npm start
```

→ http://localhost:3000 접속
→ 닉네임 + 요원 선택 → **매치 참가하기**
→ 친구도 같은 주소(같은 와이파이 or ngrok)로 접속하면 멀티플레이!

## 조작법

| 키 | 동작 |
|---|---|
| WASD / Space / C / Shift | 이동 / 점프 / 웅크리기 / 걷기(소음↓) |
| 마우스 / 좌클릭 / 우클릭 | 조준 / 발사 / 정조준(ADS) |
| R / 1 / 3 | 재장전 / 주무기 / 나이프 |
| Q / E | 요원 스킬 |
| X | 궁극기 (킬 6회 충전) |
| 4 (길게) | 스파이크 설치 / 해체 (사이트 안에서) |
| B | 상점 (BUY 페이즈) |
| Tab | 스코어보드 |
| Enter | 채팅 |
